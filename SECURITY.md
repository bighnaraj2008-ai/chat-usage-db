# Security Policy

| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT file a public issue.
Instead, send an email to bighnaraj2008@gmail.com.
We will respond promptly to investigate and release a security advisory if necessary.
