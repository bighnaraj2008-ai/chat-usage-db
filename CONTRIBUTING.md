# Contributing to chat-usage-db

Thank you for your interest in contributing to `chat-usage-db`!

## Code of Conduct
We are committed to providing an open and welcoming environment for everyone.

## Getting Started
1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Install the Rust toolchain via `rustup`.
4. Run `cargo test` to verify your environment.

## Pull Request Guidelines
- Ensure all tests pass: `cargo test`.
- Verify formatting: `cargo fmt --check`.
- Run clippy: `cargo clippy -- -D warnings`.
- Document new functionality in `README.md`.
- Keep commits atomic and informative.
