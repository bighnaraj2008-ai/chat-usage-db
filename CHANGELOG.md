# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-17

### Added
- Relational SQLite schema for users, conversations, and messages.
- Embedded migrations runner with automatic version tracking.
- Token consumption tracking service and cost calculation methods.
- Comprehensive CLI supporting migration, seeding, and analytics query commands.
- Benchmark and test harnesses with in-memory SQLite support.
- Multi-stage Docker containerization support.
